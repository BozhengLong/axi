# 练习需求：统计任务状态

本目录包含虚构的练习数据。目标是体验 Axi 的读文件、写代码、运行和连续修改流程。

请用 Bun 和 TypeScript 实现 `stats.ts`。不要增加依赖。

运行方式：

```sh
bun run stats.ts tasks.md
```

程序读取命令中指定的 Markdown 文件，统计以下三种任务行：

- `- [ ]` 表示未开始。
- `- [~]` 表示进行中。
- `- [x]` 表示已完成。

程序输出三个状态的数量。每项使用独立的一行，标签依次为“未开始”“进行中”“已完成”。标题、空行和普通文字不计入任务。

保留 `tasks.md` 和本需求文件。实现文件和试验产物放在当前目录。完成后实际运行程序，报告观察到的输出。
