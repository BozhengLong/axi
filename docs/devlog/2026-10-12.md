| 决策 | A 方案与取舍 | B 方案与取舍 | 当前推荐及理由 |

- D3 的确认单位是一次 bash 调用。确认前展示完整命令；确认机制不提供进程隔离。
- D4 选择默认档位。保留原设计中的 `/effort` 切换方案，具体档位收益待实验确认。

### 实现细节

- 历史只追加完整消息。流中断或参数 JSON 无效时，不执行工具。每个已接受的工具调用均配对结果，中断也不例外。
- 临时错误最多重试 3 次。参数与认证错误不重试。重试和请求等待可以中止。
- 每次 bash 使用新进程组。默认超时 120 秒，最多 600 秒。超时、中断或调用结束时回收同一进程组的残留进程。
- 输出采用有界缓冲区，超过 30000 个 Unicode 字符时保留头尾。展示层将控制字符转为可见文本，不修改历史或实际命令。
- 日志采用独立文件名和 `0600` 权限。不记录认证头；原始日志留在被 Git 忽略的 `.axi/` 中。
- 本地 CLI 集成测试最初受到开发机器代理影响，返回 503。测试进程移除代理变量后通过。产品进程仍沿用用户的代理环境。
