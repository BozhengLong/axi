# Axi v0.0.2 Quickstart

Use the platform listed in the [release notes](https://github.com/BozhengLong/axi/releases/tag/v0.0.2). The installer runs as your current user.

```sh
curl -fL https://github.com/BozhengLong/axi/releases/download/v0.0.2/install.sh -o axi-install.sh
bash axi-install.sh install v0.0.2
export PATH="$HOME/.local/bin:$PATH"
axi --version
axi setup
```

Choose the provider and model ID. Use the provider's API key, an environment variable, or a key entered at the start of each session. The optional connection test sends one short prompt and can consume quota. Named configurations use `axi --profile NAME`.

| Connection | What you need |
|---|---|
| Anthropic Claude API | A Claude Console API key for the selected Claude model. |
| OpenAI API | An OpenAI Platform API key with access to the selected Responses model. |
| DeepSeek | A DeepSeek API key. |
| OpenRouter | An OpenRouter API key and an available model route. |
| Bailian Coding Plan (China mainland) | A Coding Plan key beginning with `sk-sp-` and access to a model in the plan. |
| Existing Anthropic-compatible gateway | With no profile configuration, set `ANTHROPIC_BASE_URL` and `ANTHROPIC_API_KEY` as in v0.0.1. For a new profile, select the custom endpoint and Anthropic Messages. |

The release notes list the provider and model combinations tested for that build. Claude.ai and ChatGPT subscription login are outside these API options.

Open a temporary Git project for your first task. Run `axi`, enter `/permissions strict`, and ask Axi to read a file and propose a small change. Review the full write preview or shell command. Enter `y` to approve that one tool call. Enter `n` or press Return to deny it. Session traces are stored locally under `.axi/logs/`.

Run `bash axi-install.sh rollback VERSION` to switch to a verified version already installed. Run `bash axi-install.sh uninstall` to remove installer-managed versions. The installer preserves profiles and project traces.
