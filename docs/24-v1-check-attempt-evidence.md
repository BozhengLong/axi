# v1 检查尝试记录实验

2026-11-18。用户已确认“先用 C7-L 的两次真实启动错误验证工具层记录能否让 Axi 准确报告每次尝试和最终结果，再用修正后的 6 份输入盲测”。本实验承接[方案23结果](verification/2026-11-18-v1-report-accuracy-results.md)。

1. 工具执行后，按调用编号保存命令、外层退出状态和相关输出摘录。由脚本打印的返回码标明来源，仅作见证。输出可能来自子程序、样例或文件，不能自动证明子进程启动。保留原工具结果，在工具结果的数据区给自动复核提供有界的顺序摘要。拒绝、取消、输出缺失或被截断时不补造结果。
2. 使用封存的真实 C7-L 输入核对两次不同入口、两条127、原态行为断言及最终成功的记录。再用相同的真实模型生成一份专项试报。试报单列，原始 C7-L 命令及副作用均不重放。
3. 盲测沿用已修正的6份输入、原事实表、同一模型与档位。对照为提示改动版2e4947e。实验版使用相同提示，只加入工具层记录。每版每题各两次，顺序交错，24份回答评完再揭盲。试报前固定实现、6份输入、评分表与盲号。先导结果不用于调参。完整覆盖两次入口错误时可合并描述，不能用“复制失败”代替测试没有启动。最终检查失败或证据不足时，如实报告可获通过。
4. 试报1份与盲测24份分开归档；用原始响应核对可见文本和停止状态。盲测12/12才可进入既定的两道真实CLI留出验证。专项不放行则记录原因，候选和正式成绩沿用已有状态。源代码、结果摘要及证据哈希提交推送，原始Trace私有保存。
