# v1 实现与确定性验证

2026-11-12。产品冻结提交 `0bde765`；产品源码与 `7827eaa` 相同。本文记录产品门槛和环境准备，不代替 D7 的真实任务结果。依据：[v1 设计](../07-v1-design.md)、[39 组验收矩阵](../../evals/specs/v1-tools-v1/acceptance-matrix.md)。

## 已实现的行为

- 增加 read/glob/grep/write/edit，保留 bash。默认 project 自动执行经过校验的普通项目只读操作；strict 全部逐次确认。修改与 bash 在两种模式都须确认。
- read 的版本绑定完整文件、路径、身份、模式和本次会话。edit 只接受唯一精确匹配与有效版本；write 只创建新文件。确认后的提案不可重算或复用。
- 完整差异先展示，再检查外部变化并提交；过大的可见预览直接拒绝。临时文件发布前检查内容与身份，提交后回读核对实际结果。
- Ctrl+C 不撤销已完成修改；尚未开始的同批工具补齐取消结果。提交后收到取消仍保留实际 applied；未知状态与关键日志失败停止后续工作。
- 原生日志版本 3 关联会话、轮次、工具、自动或人工授权、提案、提交与取消。Trace 归档封装仍为版本 2，两者不是同一个版本号。

## 已发现并修正的问题

- 最初路径测试使用 macOS /var 别名绝对路径，与真实根目录不同；夹具改为与 CLI 相同的 realpath，没有放宽路径保护。
- 新增测试夹具遗漏捕获读取提示；修正夹具。实现中补充了仅 task_end 记录失败时的提示，避免谎称日志完整。
- 模拟控制器首次把 readline 重绘产生的 `>` 当成确认文本。控制器只移除已识别的控制序列，保留普通正文的 `>`，之后模拟通过。产品源码未因此改变。
- 新任务原上游测试尝试写只读依赖缓存；用公开固定 AVA 配置关闭缓存。固定 TypeScript 不支持 `--ignoreConfig`；删除该无效参数。两者在正式模型运行前发现，不能算候选失败。

## 保证范围

文件工具不是操作系统沙箱。用户批准的 bash 可使用宿主用户权限。原子替换保障观察者不会读到半份目标，不保证阻止任意外部进程在最后版本检查之后竞争写入。只验证同进程组子进程清理，不保证终止主动脱离该组的进程。崩溃、断电、SIGKILL 与正常 Ctrl+C 分开，本阶段没有恢复或回滚机制。

本报告尚不提供新任务成功率或 v1 发布结论。正式任务必须在实现与验收冻结后运行，全部保留结果，再单独审查报告和新增回归的实际含义。
