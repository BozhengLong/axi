## 设置和协议

- `axi setup` 可在非 Git 目录运行。测试核对了命名配置、默认配置、取消、并发更新、`0600` 文件权限和重开会话后的读取。在无用户配置时，原 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_API_KEY` 仍可启动。原网关 OAuth 过期重试用已有用例复验。
- 启动入口和做连通测试前须经过配置选择。连通测试只发一条短文本。macOS 用实际独立二进制保存并重读钥匙串临时凭据。两种 Linux 架构在禁用网络且没有 Secret Service 的容器内验证创建失败、改用环境变量和重开会话。合成 Key 检查覆盖遮掩输入、子进程环境、Trace 和文件。
- Anthropic Messages、OpenAI Responses 和 Chat Completions 分别构造请求并检查流终态。离线用例覆盖工具标识与结果回传、Responses 无服务端状态重放、DeepSeek 思考续轮、普通 401、429、断流和乱序。新适配器的离线证据与下表的真实接入证据分别统计。
- 冻结产品通过 TypeScript 类型检查和 225 项测试。开发分支合并树通过 274 项测试。两套测试在 Ollama 与其他验证并行时出现测试超时。保留并行失败回执。停止临时 Ollama 服务后按同一命令串行复验，两套均通过。该树的全库类型检查与合并前输出相同。两份输出均有 5 条旧评测脚本错误，位于 `release-r2/bun-observer.ts` 与 `release-r2/pipeline-one.ts`。
