## 4. 历史缺口与保留边界

修复前 24 个有效样本的请求/响应、CLI、权限、文件快照与验收记录均已保留。原有 201 个文件没有覆盖，另补存了经原哈希核对的源码副本。

旧批次没有导出全部原生容器日志，Claude Code stderr 也没有单独保留。旧容器已销毁，这些缺口无法补回，已在索引中标明。中止批次的 2 个样本也仍保留，不进入成绩。

API 返回的思考摘要和签名可以保存；服务端未返回的内部推理无法取得。工具自身已经截断的内容不能还原。Trace 是请求与响应事件记录，不是网络抓包或文件系统逐操作录像。
