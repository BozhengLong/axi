## 3. 实际验收了什么

- T1：文件数、UTF-8 内容字节数、指定项目信息与独立计算一致；输入文件保留，没有新增普通文件。
- T2：三轮在同一会话内完成；第一轮没有改文件；初版输出 3、1、2；追加后输出总数 6、完成率 33.3%。空输入、CRLF、普通文字、缩进和非法任务标记均接受独立校验。
- T3：修复后保留导出函数和命令行接口；原公开测试没有改动；空输入、BOM、大小写 X、CRLF、任务行边界通过。
- T4：去重覆盖、Unicode 码点排序、汇总与空目录通过；非法 JSON、空 id、负数、小数、总和越界或缺失目录时失败，并保留已有输出或不创建输出。

验收器和标准答案留在控制器侧，生成程序在另一个无网络、无凭据的容器运行。前置检查还使用正确实现、错误实现和篡改输入的样本，验证验收器能区分结果。

## 5. 对齐了哪些条件，还有哪些差异

所有正式请求的模型标识为 `claude-opus-5-5`、effort 为 `medium`，已解析的完整响应模型标识也一致。两边通过同一个转发服务到同一个上游网关。该核对不能证明网关内部使用的模型权重相同。

以下设置保留产品原生行为，实际请求中存在差异：

| 项目 | Axi | Claude Code |
|---|---|---|
| 工具 | bash | Bash 与原生文件工具，另有评测权限通道 |
| 主入口 | 真实终端 CLI | 真实 CLI 的结构化非交互入口 |
| 系统提示与上下文管理 | Axi 当前实现 | Claude Code 默认实现，个人扩展隔离 |
| 正常流式请求 max_tokens | 64000 | 128000 |
| thinking display | summarized | updates |
| 本批实际协议 | 59 次流式请求 | 67 次流式请求、2 次普通 JSON 请求 |

所以这是同题产品比较，不是只改变某一个架构部件的实验。本轮没有评价终端外观，也没有运行联网、subagent、复杂依赖或长上下文任务。生成程序使用 Bun 实际执行，没有额外要求它们通过仓库的严格 TypeScript 编译设置。

## 6. 异常、恢复与未通过的既有检查

### 上游限流

Claude Code 的两个正式运行收到网关的 429 事件：T3 第 1 次、T1 第 1 次。它随后以普通 JSON 请求恢复，最终任务均通过。这些请求与等待时间保留在原样本，没有删掉后重跑。

T1 的该次运行还记录了一条流读取异常标记。它与限流运行重合，现有证据不足以单独判断是连接关闭、取消还是独立网络故障，因此不额外计算一次故障。

本批 Axi 样本未收到同样的 429 事件。因此不能用这组自然发生的异常证明两者在相同故障输入下的恢复差距。耗时比较也受这一环境波动影响。

### 确定性恢复专项

固定假响应下，两边都验证了：逐次授权、拒绝后保留原文件并另存、中断后延迟写入不发生、后续对话继续。这些专项不并入 12 次真实任务的成功率。

### Axi 的已知缺陷

| 编号 | 本次实际观察 | 状态 |
|---|---|---|
| R1 | 提前输入 y 并移到行首后，确认时只回车仍返回允许；专项没有执行命令 | 仍存在，优先修复 |
| R2 | Bun 1.3.14 的真实连接拒绝返回 Error / ConnectionRefused；Axi 只请求 1 次 | 仍存在 |
| R3 | 在临时外部 Git 仓库创建日志后，日志显示为未跟踪文件 | 仍存在 |

详细位置和复现条件见[仓库检查记录](2026-11-10-repo-review.md)。既有 31 项测试仍然通过，这也表明已有测试未覆盖上述条件。

## 7. 中止批次的处理

初始批次 `b20261110141641` 执行了 2 个正式样本后暂停。控制器误把 Claude Code 的参数规范化当成不匹配，并错误处理网关的结束标记，影响了执行。**两边这对样本都没有进入最终比较**，原始结果和失效说明保留。

修复仅涉及测试设施：按原生调用 ID 配对、检查实际执行参数范围、同时记录原始和实际参数；支持普通 JSON 响应；观察器不改变原始流。补充前置回归后，新批次重新从初始文件执行完整 24 个样本。没有根据产品成败挑选结果。

每类编程任务选第 1 次样本，隐藏工具名称并随机编号，先写观察再读取映射。该检查只补充说明，不影响通过成绩，也不产生主观总分。

- T2：Axi 产物较短，直接计算并格式化完成率。Claude Code 补充了文件不存在时的提示和说明，代码稍多。两者均通过边界检查。
- T3：两者实现接近。Axi 用显式码值检查 BOM，较易辨认；Claude Code 产物包含不可见 BOM 字面字符，阅读时不够直观，但功能结果通过。
- T4：Axi 在全部校验后直接写出结果。Claude Code 增加临时文件和重命名，提供了超出本轮输入校验要求的写入保护，同时代码更长。额外字段是否应拒绝在题面中不够明确，未用这一点改变成绩。

本观察支持“实现取舍不同”，不支持笼统宣称某一工具生成的代码质量更高。
