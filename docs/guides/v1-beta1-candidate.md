## 安装与使用

按 [README](../../README.md) 使用 Git checkout、Bun 1.3.14 与 `bun install --frozen-lockfile`。本版本以源码交付，没有 npm 或 Homebrew 安装包。在其他项目目录通过 Axi 入口绝对路径启动，当前目录是文件工具根目录，也是 `.axi/logs/` 的保存目录。API 地址和 key 由环境变量或本地 `.env` 提供；不要提交凭据。

默认 `project` 模式允许受路径规则约束的读取。`strict` 模式逐次确认读取；两种模式的 bash、write 和 edit 都须批准。只有当前单独的小写 `y` 表示批准。默认拒绝。edit 依赖读取版本，确认期间目标改变会拒绝旧提案。write 只创建不存在的文件，不创建缺失父目录。

默认收尾复核只执行一次，仍使用同一模型。发生文件修改或获准执行 bash 后，工作阶段最多 40 次实际生成请求，复核最多 10 次，总计 50 次；重试计入。只读问答和全部拒绝不触发复核。`/review off` 时整轮最多 50 次。复核不保证正确性；原生 completed 不是独立验收通过。见[复核说明](bounded-review.md)。

## 已知范围

- 只支持单行交互与当前进程内历史；退出后不恢复会话。多行粘贴不会预先授权后续操作。
- 没有操作系统沙箱。获准的 bash 具有当前用户权限；文件工具的根目录约束不限制 bash。
- 文件工具只处理支持范围内的普通 UTF-8 文本，最多 1 MiB。搜索可能不完整，须检查返回范围和原因。完整修改预览超过展示上限会拒绝提案。
- bash 默认 120 秒，最多 600000 毫秒；取消/超时清理同进程组。主动脱离进程组的进程不在保证内。已发生的修改不会自动撤销。
- 工具输出超过 30000 个 Unicode 字符会截断。Trace 保存可观察请求、响应、工具结果和授权；无法恢复工具已截断的内容，也不声称取得服务端未公开推理。
- 日常原生日志默认保留，权限 0600。它可能包含任务与文件内容，即使不记录认证头也应保密。评测完整证据包另含终端、文件快照、评分、审查和校验记录，原始内容保存在私有目录。见[日常 Trace](daily-trace.md)。
