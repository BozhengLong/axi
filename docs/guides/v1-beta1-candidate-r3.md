## 安装与日常使用

按[README](../../README.md)使用Git、Bun1.3.14和`bun install --frozen-lockfile`。本版本仍以源码交付。API环境变量由用户提供；从普通项目目录使用候选`src/main.ts`的绝对路径启动，启动目录是文件工具根及`.axi/logs/`保存位置。完整步骤见[本机试用](v1-first-use.md)。

工作、一次复核与整项任务都不设请求次数上限。默认auto在符合条件的正常初稿后复核一次；off不添加复核。连续临时故障在每次逻辑模型调用的恢复窗口内重试，默认600000毫秒，可通过`AXI_RETRY_WINDOW_MS`配置；单次请求最多5分钟且受剩余窗口约束。窗口耗尽明确报告未完成，保留文件与Trace；成功后下一调用独立计时。实验外部30分钟窗口不写入日常产品。见[运行说明](task-execution.md)。

文件读取默认project模式受路径及身份校验约束，strict逐次确认；bash、write和edit始终逐项确认。没有操作系统沙箱。Ctrl+C停止当前轮但不撤销已完成修改。当前没有退出后恢复、上下文压缩或持久shell，不能将不限次数理解为可以无限上下文长跑。

Trace版本4默认开启，权限0600，含可观察请求/响应、SSE、工具与授权记录。它可能包含任务和文件内容；不记录认证头，不包括API未公开推理或工具已截断输出。保存位置与限制见[日常Trace说明](daily-trace.md)。
