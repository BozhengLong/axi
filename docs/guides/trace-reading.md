# 如何查看 Axi / Claude Code 的运行轨迹

Trace 是一次任务的可观察调用链。它用于核对模型收到什么、提出什么工具调用、哪些操作获准、执行返回什么，以及产物是否通过验收。

## 先打开批次索引

每个正式批次保存于 `~/.local/share/axi-evals/<batch-id>/`。完成运行后，可生成导航文件：

```sh
bun run scripts/eval/trace.ts
```

它为当前批次生成 `TRACE-INDEX.md`。也可以给出其他批次的绝对路径，生成对应索引。索引按任务、重复次数和工具排列，链接到每个运行的记录。

修复前的有效基线是 `b20261110144129`。其 24 个样本原有文件已保留并记录校验值，同时补存了经过原哈希核对的源码快照。

## 记录版本 2 的内容

| 文件 | 内容 |
|---|---|
| `manifest.json`、`source-snapshot/` | 题目、固定顺序、模型配置、版本和原始源码副本 |
| `io.jsonl` | 带时间戳的输入、输出、中断、错误和进程结束事件 |
| `terminal.txt` | Axi 原始终端文本；伪终端中的 stdout/stderr 合并 |
| `claude.jsonl`、`stderr.txt` | Claude Code 的结构化输出和独立标准错误流 |
| `relay/<运行 ID>.jsonl` | 模型请求体、SSE 原始事件文本与解析结果、普通 JSON 响应、权限决定、重试及异常 |
| `native/axi-session/` | Axi 自身的会话日志，包括每个工具结果与任务耗时 |
| `native/claude-session/`、`native/claude-debug.log` | Claude Code 原生会话记录与调试日志 |
| `execution.json`、`final-files.json` | 每轮完成后的文件快照、最终产物和执行状态 |
| `trace-manifest.json`、`TRACE.md` | 文件字节数、SHA-256、缺失或截断原因，以及逐运行导航 |
| `results.json` | 独立验收条件和实际结果 |

JSONL 表示每行一个 JSON 事件。平时先读 `terminal.txt` 或 `claude.jsonl`。需要检查输入时机时，再读 `io.jsonl`。其中原始终端字节使用 base64 保存，以免控制字符或 UTF-8 分片丢失。

`complete_observable` 表示本方案要求的可观察渠道已收齐，不表示任务验收通过。`partial` 表示存在明确缺口。生成源码若超过工具自身的输出上限，原始工具结果可能已截断；控制器不能恢复未收到的内容。

## “完整”的边界

- API 返回的思考摘要、签名和正文保留。服务端没有返回的内部推理过程无法取得。
- 保留模型请求与响应事件，不记录真实认证头；这不是网络抓包，不能恢复底层 TCP 分片。
- 文件内容按用户轮次和任务结束时快照保存，不是每一次文件系统调用的录像。
- 标记超限、日志缺失和不完整 JSON 行。不会把部分记录静默称为完整。
- 修复前的版本 1 已有请求/响应、CLI、权限、快照和验收记录，但原生容器日志和独立 stderr 当时未完整归档。旧容器已销毁，不能事后补回。

## C6 连续任务补充

[C6 合并索引](/Users/spidey0o0zheng/.local/share/axi-evals/c6-20261111/TRACE-INDEX.md)包含 10 条真实轨迹，涵盖试跑、环境不可判定、被替换的原配对和正式采用样本。每条增加三轮题面/反馈、稳定文件与 Git 快照、独立成绩、暂停/恢复及用户策略修改记录。复验入口见 [C6 指南](c6-evaluation.md)。

C6 历史模型运行的转发器未保存或透传上游 Retry-After 等响应头。`complete_observable` 只表示当时 Trace v2 约定的记录齐全，不能当成全部 HTTP 元数据完整。这个历史缺口无法事后补回。全部模型运行结束后，新转发器已增加允许的重试、限流、请求 ID 等响应头，并关联请求序号和轮次；认证及 Cookie 不采集。

当前原生会话导出上限为 128 MiB。超过上限或导出失败必须在清单中标记缺口。正式运行前已用 41,943,077 字节合成日志验证跨越旧 32 MiB 上限的完整导出和哈希一致性。

## 保留与共享

每轮先导出日志并生成清单，再销毁容器。`core.ts cleanup` 只清理测试容器和网络，不删除宿主机的证据。当前脚本不设置 trace 自动删除期限。

原始证据保存在本机私有目录，目录权限 `0700`、文件 `0600`。旧批次不被新批次覆盖。源码快照和校验清单用于复核版本和发现意外修改。

原始内容可能包含任务、源码、命令输出及 API 返回数据。需要共享时使用仓库中的脱敏报告，不直接上传整个私有目录。
