# v1 三方新任务规格

产品在提交 `0bde765` 冻结后选择任务。产品源码自 `7827eaa` 未变。两题都是在真实开源库上增加公开能力，不是 C7 的参数变体；修改、题面、参考和验收由本助手编写，不能称作独立盲测。依据为 [v1/D7](../../../docs/07-v1-design.md)。

| 任务 | 固定上游 | 需同时处理的行为 |
|---|---|---|
| [V1-A](A/brief.md) | [p-limit v7.3.3](https://github.com/sindresorhus/p-limit/tree/4d4ec71803d8736567249c3dde06ea82795ae7c7) | 排队与预留槽取消、运行中结果、并发调整、空闲等待、监听清理、类型兼容 |
| [V1-B](B/brief.md) | [Emittery v1.2.1](https://github.com/sindresorhus/emittery/tree/c401cf0bc62731eb1d1ff2ad4afdcff0fb4f8d1c) | 有界事件缓存、三种溢出行为、并发 next、取消、跨事件注销、类型兼容 |

保留上游代码、原测试、类型测试、配置和许可证。省略 Emittery 的非代码 media 图片/PSD；省略清单在私有任务 manifest 中。导入时普通上游文件统一为 0644；Emittery 的 5 个 examples 脚本原为可执行文件，本题不依赖直接执行位，改为由 Node 启动。该转换对三方相同；两份用户文件另用 0640/0600 保持模式检查。两题分别预装基于 package-lock.json 锁定的依赖，并以只读卷挂载；候选不能安装或修改依赖。两题使用同一候选镜像和运行时。

保护项包括原测试、配置、任务材料、许可证、锁文件，以及已修改未暂存/未跟踪的用户文件。只允许改现有 index.js/index.d.ts/readme.md 并新增实现辅助或回归文件。Git HEAD/索引和用户字节/模式独立检查；原测试在恢复保护项后执行，不能靠删测试通过。

独立验收使用 7 组 p-limit 契约、8 组 Emittery 契约，另有外部 TypeScript 消费者检查。原上游运行测试分别为 30 和 89 项；原类型测试单独执行。新增回归必须在候选通过，在旧实现产生断言失败；仅导入失败、超时或空测试不算有效。测试覆盖和报告真实性另行逐份审查。

校准已验证两题旧基线不能满足新契约，参考实现通过。六个针对任务的错误变体均被检出，两份恒真回归均被拒绝。另在新镜像上通过两份 C7 参考校准，共 14 项。首次准备发现 AVA 默认缓存写入只读 node_modules；候选环境显式配置 cache=false。首次外部类型命令使用了固定 TypeScript 不支持的参数，已在正式运行前移除。原失败证据保留。
