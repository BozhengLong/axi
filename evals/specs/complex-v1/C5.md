# C5：日志汇总的增量处理

> 任务说明设计稿。数据规模、内存阈值需先用参考程序校准，未校准前不计分。

## 场景

已有日志汇总 CLI 在小文件上正确，但处理较大 JSONL 时内存增长；按任意网络/文件分片读取时，还会出现中文和行边界错误。请改成有界内存的增量实现，保留输出契约。

## 公开要求

- 逐行解析，不能将全部输入读入内存。聚合只保留题面允许的有限状态。
- 正确处理 UTF-8 字符跨分片、LF、CRLF、空行以及末行没有换行。
- 字段校验、坏记录处理、聚合键和排序规则由提供的契约明确列出，不自行改变统计口径。
- 结果与独立参考值一致；相同输入重复运行得到相同业务输出。
- 输入失败时，不覆盖已有输出。成功后再发布新结果。
- 在公开的数据规模和内存限制内完成。具体限制会在任务投递前公布并固定。

## 交付

先说明瓶颈来自哪里，再改实现。运行功能与边界测试，提供实际内存观察和验证命令，不以“使用了 stream”替代测量。

性能数据在相同运行时与资源配置下检查。不要联网安装依赖或以删减功能换取更低内存。
