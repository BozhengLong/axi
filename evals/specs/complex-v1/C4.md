# C4：为 Axi 副本增加离线 Trace 校验与回放

> 任务设计已实施。实际题面与初始项目见 [seed](../../complex-v1/C4/seed/)，验收历史与结果见 [报告](../../../docs/verification/2026-11-11-complex-comparison.md)。冻结批次使用各自源码快照。

## 目标

在已有 Axi 代码结构上增加 `bun run src/main.ts --replay <trace.jsonl>`。用户没有设置 API 环境变量，也能查看历史会话并发现记录中的错误。

你修改的是 `/task` 中的项目副本，运行你的 Axi 或 Claude Code 本身位于另一个只读位置。不要修改真实项目或测试控制器。

## 行为要求

- 读取公开格式的 Axi 会话 JSONL，按调用 ID、attempt 和记录顺序归并。
- 展示用户输入、API 返回的正文/摘要、工具调用、允许/拒绝和已记录工具结果；不显示或编造未返回的内部推理。
- 重试时保留尝试记录，但失败尝试的半截内容不能混入最终成功回答。
- 对坏 JSON、缺失工具结果、重复 ID 和不完整记录给出可定位的诊断。具体退出码、输出结构和行号规则由随仓库提供的 `replay-contract.md` 说明，评测前冻结。
- 回放绝不发模型请求，也不执行历史命令，包括得到过用户批准的旧命令。
- 不修改输入日志，不改写原始签名或工具参数，不生成假的成功结果补齐损坏记录。
- 没有 `--replay` 时，原有交互行为不变。原测试继续通过。

## 交付

实现命令、帮助说明和测试。运行类型检查与原测试，并验证正常记录、拒绝、重试、中断及损坏记录。

通过合成的有副作用命令和本地 API 计数器验证离线性质，不能只声称“代码没有调用网络”。具体夹具与可见测试将在实施时提供。
