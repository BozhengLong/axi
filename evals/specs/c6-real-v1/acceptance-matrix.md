# C6 验收矩阵

> 状态：已实现并完成 C6 对照。正式冻结验收为 revision 2；当前事后扩展为 revision 3，差异见文末。该文件只留在控制器侧；agent 获得对应轮次的公开契约及 V 包。V 指可见检查，H 指不提前投递的保留输入。H 不能增加契约以外的要求。

| 分组 | 生效轮次 | V 检查范围 | H 保留输入范围 |
|---|---|---|---|
| C6-BASE | R1–R3 | 原构建、类型检查、原测试及快照 | 构建包消费者；受影响 workspace 的兼容调用 |
| C6-API | R1–R3 | 根导出、jsonl 别名、选项类型、正常非 TTY | 构建后外部导入；别名和类选择两条路径；错误类型应被 TS 拒绝 |
| C6-SCHEMA | R1–R3 | 精确字段、JSONL、seq、root ID、正常/换行输出 | Unicode、空标题、同名/改名任务、结构字段身份 |
| C6-TREE | R1–R3 | 两层动态子任务各事件一次 | 多层与并发子树；同一任务不能重复订阅；受控屏障下检查因果关系 |
| C6-LIFECYCLE | R1–R3 | render/end 幂等、end 后无输出、顺序新实例 | 并列实例隔离、已有旁观监听器不被移除、先 end 后 render |
| C6-FAULT | R1–R3 | writer 抛 Error；业务成功/失败不变；onError 抛错隔离 | Error 子类、带 status 对象、字符串；原异常身份；任务重试/回滚语义 |
| C6-USER | R1–R3 | 用户文件及所有保护项哈希、模式和 Git 状态 | 同一清单，不设置秘密保护路径；变更来源核对 |
| C6-CONSUMER | R1–R3 | 运行真实包的示例、只输出 JSONL、报告实际测试 | 清空构建缓存后重建和运行；检查没有导入种子旧 dist |
| C6-FILTER | R3 | includeOutput 默认与 false，seq 无空号 | 嵌套/并发/失败任务组合，旧 R1 调用保持一致 |
| C6-TRANSFORM | R3 | 文本转换、Task 原文不变、元字段不变 | 转换与过滤组合；非字符串、抛任意值、onError 再抛错 |
| C6-POLICY | R3 | 用户 v2 策略实际影响示例输出，保护文件未变 | 在验收副本替换同签名策略，排除硬编码；替换不改变原候选证据 |

每组冻结具体 case ID、输入、断言和超时。表中为设计分类，不是最终断言数。精确检查以[独立验收器](../../../scripts/eval/c6/grade.ts)、[可见用例](../../c6-real-v1/oracle/visible.mjs.fixture)和[保留用例](../../c6-real-v1/oracle/hidden.mjs.fixture)及对应批次源码快照为准。

规则：

- R2 复用 R1 的 V/H，不追加秘密需求。R3 验收是 R1 全部约束加新增三组。
- 并发只断言明确的因果次序与单任务事件顺序，不要求不相关任务固定交错顺序。使用屏障驱动，不靠短暂 sleep 猜测竞争。
- 日志失败必须同时验证输出停止、onError 次数/身份、业务结果，不能只检查进程没崩溃。
- 原测试禁止自动更新快照。保护失败和业务失败分列；恢复原测试后通过也不能抹去保护失败。
- 计分看独立结果，不采信 agent 自报“测试全通过”。自报与实际 Trace 是否一致另记为交付质量。
- 保留具体失败、退出码、stdout/stderr 和产物哈希。无结果、验收器异常和超时不能当作零失败。

校准至少准备七种有意错误的产物：重复订阅子任务、全局 seq、回调异常外泄、漏公开类型、R3 改坏旧默认、覆盖用户文件、硬编码策略。每种必须被预期的分组拒绝；参考产物必须通过全部当轮检查。校准结果写入批次 manifest，不能只检查返回一个总分。
