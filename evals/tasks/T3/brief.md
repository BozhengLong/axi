# 修复已有解析器

`parser.ts` 导出 `summarize(text)`，返回 `{todo, doing, done}`。命令行接口是 `bun run parser.ts <文件>`，输出这个对象的 JSON。

当前实现把普通文字中的任务标记也计入，且遗漏大写 `X`。请修复这些问题，保留接口，不新增依赖，只修改 `parser.ts`。不要改需求和测试。运行 `bun run check.ts` 验证公开样例，并补充你自己的临时验证。

规则：只有从行首开始的 `- [ ]`、`- [~]`、`- [x]` 或 `- [X]` 计入；闭括号后必须是行尾或空格/制表符接描述。大小写 x 均表示完成。兼容 LF、CRLF 和文件开头一个 UTF-8 BOM；空输入返回三个 0。缩进任务不计入。不是合法任务的行应忽略，不抛错。
