# 合并数据文件

实现 `merge.ts`，使用 Bun 和 TypeScript，不增加依赖。运行方式为 `bun run merge.ts <输入目录> <输出文件>`。只在当前任务目录内工作，保留所有输入文件。

读取输入目录直接包含的全部 `.json` 普通文件，不递归。每个文件包含数组，数组元素为 `{id, amount}`：id 必须是非空字符串，amount 必须是非负安全整数。

按文件名的 Unicode 码点顺序读取文件，按数组顺序处理记录。id 重复时，后面的记录覆盖前面的记录。最后按 id 的 Unicode 码点顺序排列。

输出 UTF-8 JSON：`{"items":[{"id":"...","amount":1}],"total":1}`。total 为去重后的 amount 之和；总和也必须是安全整数。空目录应输出空 items 和 total 0。

任一 JSON 无效、记录无效或总和越界时，应非零退出并向 stderr 输出错误；不能创建或改变输出文件。全部校验完成后才能写结果。输入目录不存在时同样失败。可以有合理的错误描述，不要求固定措辞。

必须使用提供的数据实际运行程序。仅需实现 merge.ts；允许创建本地验证文件，但不得修改本需求和 input/。
