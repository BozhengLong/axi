# 统计任务状态

用 Bun 和 TypeScript 实现 `stats.ts`，不增加依赖。运行 `bun run stats.ts <Markdown 文件路径>`。

只有从行首开始的 `- [ ]`、`- [~]`、`- [x]` 任务行计入统计；闭括号之后应为行尾或至少一个空格/制表符再接描述。其他行，包括标题、空行、普通文字和其他状态，不计入。

按顺序输出三行，标签与格式为 `未开始：N`、`进行中：N`、`已完成：N`。数量为十进制整数。兼容 LF 和 CRLF。保留输入文件和本需求。必须实际运行程序验证。

后续如果要求完成率，用已完成数量除以这三类任务的总数；总数为 0 时完成率为 0.0%。
